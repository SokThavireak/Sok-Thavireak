# Sok Thavireak - Portfolio Website

Personal portfolio website for **Sok Thavireak**, Full-Stack Website Developer & IT Administrator. Built with HTML5, Vanilla JavaScript, and Tailwind CSS.

## 🚀 Key Highlights
- **Modern Clean Light Theme**: Elegant white aesthetic with balanced typography, subtle shadows, and glassmorphic navigation.
- **Interactive Project Galleries**:
  - **Omnichannel POS & E-Commerce (New Release)**: 19-screenshot interactive gallery modal showcasing customer web storefront pages (catalog, shopping bag, order tracking, retail locations), cashier point-of-sale terminals, real-time inventory synchronization, immutable restock ledgers, and 4-tier JWT RBAC ([GitHub](https://github.com/SokThavireak/pos-and-ecommerce)).
  - **Pop Commercial Photograph Studio**: 8-screenshot interactive gallery modal showcasing commercial studio photography showcase, tiered pricing matrix, production journal, staff operations dashboard, and secure client sign-in/up portals ([GitHub](https://github.com/SokThavireak/pop-commercial-photograph)).
  - **Full-Stack HRMS**: 13-screenshot interactive gallery modal showcasing Spring Boot + React admin workflows, payroll, leave management, and dashboard architecture.
  - **Murakami Sushi Store & POS**: 8-screenshot modal showcasing multi-role dashboard and e-commerce workflows.
  - **SFL Cambodia Landing Page**: Institutional UI optimization and mobile-first responsive design.
  - **Pidan Khmer Silk Shop Inventory (In Progress)**: Specialized artisan textile inventory system built with Docker, Nuxt.js (Vue 3 SSR), NestJS microservices, and PostgreSQL.
- **Fullscreen Lightbox**: Click to enlarge project screenshots with keyboard navigation (arrow keys + ESC).
- **Mobile Responsive**: Fully responsive layout with mobile dropdown navigation.

## 🛠️ Tech Stack
- HTML5 & CSS3
- JavaScript (ES6+)
- Tailwind CSS
